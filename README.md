# Mohitha — Student Developer Portfolio 🚀
**Theme:** Cyber-Emerald / Dark Mode  
**Specialization:** 2nd Year AIML @ KS Institute of Technology (KSIT), Bengaluru  
**Tech Stack:** React 18, Tailwind CSS, HTML5 Canvas 2D/3D Mesh, Lucide Icons


## 🚀 Highlights & Features Implemented

1. **Cyber-Emerald / Dark Mode Palette**
   - Deep matte carbon background (`#0d1117`, surface `#161b22`, deep `#070a0e`)
   - Crisp neon emerald accents (`#10b981`, `#047857`)
   - High-voltage lime highlights (`#a3e635`, `#bef264`)

2. **Subtle Animated Matrix-Dot Grid (HTML5 Canvas)**
   - Custom-engineered canvas simulation with retina high-DPI scaling.
   - Gently ripples with radial dampening waves whenever the mouse/touch cursor moves over it.
   - 3D parallax perspective tilt tracking cursor coordinates relative to screen center.

3. **Floating Frosted-Glass Navigation Bar**
   - Stays fixed at the top as the user scrolls (`backdrop-blur-xl bg-[#0d1117]/80`).
   - Monospace brand logo: `<Mohitha />` with glowing radar dot and `AIML @ KSIT` label.
   - Clean navigation links: **'Projects'**, **'Skills'**, **'Campus Journey'**, **'About'**, and **'Contact'**.

4. **Featured Projects Showcase**
   - 3D perspective tilt physics reacting to mouse movement.
   - Dynamic cursor-following radial light reflection (shine effect).
   - Filter pill row (`All`, `Web Apps`, `AI / ML`, `Mini-Projects`).
   - 'Live Demo' and 'GitHub Code' buttons on every project card.

5. **Tech Stack & Skills Showcase**
   - 3 Tidy Categories: **Languages**, **Frameworks & Tools**, and **Core CS Concepts**.
   - Official tech vector logos & icons.
   - Interactive hover scale (`scale-105`), glowing emerald border, and comfort level tooltips (`Proficient`, `Familiar`, `Currently Learning`).

6. **Education & Campus Journey (NEW)**
   - **Illuminated Vertical Timeline**: Connected by a radiant gradient emerald line with glowing nodal dots.
     - **2026 (Current)**: Pre-Final Year B.Tech & Hackathon Finalist.
     - **2025**: Core Technical Club Member / Web Lead.
     - **2024**: Began Degree & Built First Web App.
   - **2x2 Achievement Badges Matrix**:
     - 🏆 `1st Place - University Hackathon`
     - ⚡ `150+ LeetCode Problems Solved`
     - 👥 `Tech Club Organizer`
     - 📜 `Full-Stack Certified`
     - Subtle hover elevation and glowing emerald border.

## ⚡ How to Run

### Method 1: Instant Browser View (Zero Setup)
Simply open `index.html` in your web browser:
```bash
open index.html
```

### Method 2: Local HTTP Server (Python)
Run a local lightweight server in this folder:
```bash
python3 -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.
